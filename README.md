## Hosting

These pages are hosted via **GitHub Pages**. To enable GitHub Pages:
1. Go to this repo's **Settings** → **Pages**
2. Under **Source**, select `main` branch, `/ (root)` folder
3. Click **Save** — your site will be live at `https://[username].github.io/fooddecoderai-policies/`
